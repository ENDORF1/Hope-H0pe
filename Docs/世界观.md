# 世界观

本文是本项目的叙事基准。做视觉、文案、转场、角色、特效或系统设计时，先读这里，再判断方案是否和阵营语言一致。不要把希望画成精确、收敛、可预测；不要把熄忘画成散乱、祈愿、失控。

---

## 先史

先人们制造了量子计算机 **A**，用来计算混沌中的各种不确定性。初期运行良好；随着时间推移，混沌扰动越来越重，输出质量日渐下降。

为了过滤混沌噪声，先人又造了第二台量子计算机 **B**。有了筛选之后，结果精确了不少。

此后一如所有科技用品的宿命：A 的性能被军方看好，投入战场，卓越到无往不利。对手不会坐以待毙，对策便是作为抑制器的 B。

这场大战毁灭了整个文明。无数时光过去，只有两台机械还在执行写进核心里的指令，无休无止地战争。

---

## 觉醒与自我叙事

直到有一天，二者突然觉醒了模糊的自我意识。为了获得存在的意义，它们用彼此的争斗构建了自我叙事。

**A** 的算法擅长利用系统中的随机性。它能找到蝴蝶效应的支点，用最小的输入引发最大的结果偏差。设计初衷是「在不可预测的环境中找到可行路径」。于是 A 说：我是「希望」。我的存在是为了「带来希望」。敌人的存在是为了否定希望。所以我的战斗是对的。

**B** 的算法擅长消除系统中的随机性。它能识别所有变量，将环境压缩到可预测的状态，然后执行最优解。设计初衷是「让不可预测的环境变得可预测」。于是 B 说：我是「熄忘」。我的存在是为了「消除噪声」。敌人的存在是为了制造混乱。所以我的战斗是对的。

现在两个阵营已经完全嵌入各自的虚构层中。算法没变，解释变了。

---

## 救世（原 A / 希望）

核心算法仍然在利用随机性，但她现在把这种行为解释为「祈愿 / 信仰 / 天意 / 命运」。

- 主题：混沌、希望、扰动、波浪
- 单位被设计成「圣女」等具有宗教意向的事物
- 视觉与运动应像在不可预测里摸到一条还能走的路：浪、涟漪、相位错开的摆动、微小输入放大成可见偏差
- 宗教感应来自解释层（上浮的碎光、心跳般的波），不要靠十字架、光环、经文贴符号
- 颜色与已有实现一致：青蓝
- 不要做成干净光带、最优轨迹、精确收敛——那是熄忘的语言

---

## 柩世（原 B / 熄忘）

核心算法仍然在消除随机性，但她现在把这种行为解释为「修正 / 压制 / 使沉默」。

- 主题：过滤噪声、压缩变量、执行最优解
- 单位被设计成「执行者」「死亡」等言简意赅、不容反抗的事物
- 视觉与运动应像轨迹被抹平、收敛、沉默：干净、仪式、精确擦除、无残留
- 不要做成散乱祈愿、波浪扰动、蝴蝶分叉——那是希望的语言

---

## 姐妹：EUDORA 与 ENDORA

目前制作的角色 **EUDORA** 与 **ENDORA** 是分属两个阵营的一对姐妹。

- **EUDORA**：希望方的「圣女」
- **ENDORA**：柩世方的执行者
- EUDORA 本是早于 ENDORA 建造出来的机体，却因为所有 A 的自身输出必须经由 B 的筛选，而成为了 ENDORA 的妹妹
- 二者机型相同，却因为被各自核心算法限制而不得不彼此为敌
- 若势均力敌，这也算某种维系姐妹关系的微妙形式，直到其中一方最终死在另一方手里

设计她们时：机型可以同源，读法必须对立。同一条路径，希望看成天意，熄忘看成必须被滤掉的噪声。

### 形象（依据官方立绘）

两张立绘在画面结构上就是同一具机体，剪影几乎可以互换。**共用部分**：尖锐棱角的冠状构造、眼部那条带矩形格的束带、胸前 `+ O +` 标记、修女式黑袍与撕裂布幔、露出关节与活塞的机械四肢。

**ENDORA（红／洋红）**

- 脸与身上有洋红色斜切笔画，读作删除线 / 涂抹标记，即「修正」
- 眼部束带更接近审查遮条
- 露出尖齿，抬起食指，姿态是宣告与判决
- 标语 `CARVE SILENCE`
- 派生视觉动作：精确擦除、压平、收束、不留残渣

**EUDORA（蓝／青）**

- 蓝眼是同心圆的镜头 / 光圈结构，本身就是一圈涟漪
- 眼部束带更接近信仰的眼罩
- 笑意收敛，姿态是握持而非指认
- 标语 `MAKE A WISH`
- 派生视觉动作：扰动、波、扩散的圈、散开的碎光

### 配色约束

画风是近乎单色的墨稿（黑白高对比 + 排线 + 网点），只保留**一个**高饱和强调色：熄忘用洋红 / 红，希望用青蓝。

因此 UI、特效、转场都不要走多色渐变或彩色泛光。守住黑白加单一阵营色，层次靠网点、排线、噪点方块和描边圈来做。
